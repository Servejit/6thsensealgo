# 6thSense Algo Trading

Automated algorithmic-trading application under development.

## Phase 1
- Streamlit dashboard
- OHLCV CSV backtesting
- Risk parameters
- Stop-loss and target simulation
- Paper-trading foundation
- Trade journal
- Risk-control architecture
- Real-money execution intentionally disabled

## Run
pip install -r requirements.txt
streamlit run app.py

## Roadmap
1. Insert the exact 6thSense strategy conditions.
2. Add multi-timeframe market-data engine.
3. Add advanced backtest metrics.
4. Add persistent paper trading.
5. Add broker adapter.
6. Add authenticated broker connection.
7. Add live execution only after testing and required compliance.
